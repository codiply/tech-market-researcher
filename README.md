# Tech Market Researcher

## Start

```bash
./stack.sh up -d
```

The MLflow UI is then available at [http://0.0.0.0:5000](http://0.0.0.0:5000).

## Common commands

```bash
./stack.sh ps                 # status
./stack.sh logs -f mlflow_server   # follow one service
./stack.sh down               # stop and remove containers
```
